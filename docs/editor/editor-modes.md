# Editor modes

The mode switcher in the top-right of the toolbar controls how the editor area is used. It has three modes:

| Mode | What you see | Good for |
| --- | --- | --- |
| **Split** | Source on the left, rendered preview on the right | Writing while checking the result (the default) |
| **Edit** | Only the Markdown source, full width | Focused writing |
| **Preview** | Only the rendered note, full width | Reading |

Switching modes never changes or reloads your note, and the cursor position in the editor is kept.

## The editing pane

The editing pane is a code editor tuned for Markdown:

- Markdown syntax highlighting and line numbers.
- Long lines wrap instead of scrolling sideways.
- Undo and redo, find and replace, and multiple cursors. See [Keyboard shortcuts](../keyboard-shortcuts.mdx).

## The preview pane

The preview renders GitHub-flavoured Markdown, including tables, task lists, strikethrough, footnotes and syntax-highlighted code blocks. See the [Markdown syntax](./markdown-syntax.md) page for everything it supports.

It updates as you type and follows the app's [light or dark theme](../appearance/dark-mode.md).
