# Installation

Download the installer for your operating system from the [download page](/download). Older versions are on [GitHub Releases](https://github.com/AlbertArakelyan/Lumark/releases).

<Tabs groupId="os" queryString>
  <TabItem value="windows" label="Windows" default>

1. Download the `.exe` installer from the [download page](/download).
2. Open the downloaded file.
3. Follow the installation wizard.
4. Launch Lumark from the Start menu.

:::info[Windows SmartScreen]
If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears for apps from smaller publishers that Windows hasn't seen many times yet.
:::

  </TabItem>
  <TabItem value="macos" label="macOS">

1. Download the `.dmg` from the [download page](/download).
2. Open the downloaded file.
3. Drag **Lumark.app** into the **Applications** folder.
4. Open Lumark from Applications or Launchpad.

:::info[Apple Silicon: coming soon]
The current `.dmg` is built for Intel (x64) Macs. A native build for Apple Silicon (M-series) Macs is coming soon. Until then, Apple Silicon Macs run the Intel build through Rosetta 2.
:::

:::info[Lumark can't be opened]
If macOS refuses to open the app the first time, right-click (or Control-click) **Lumark.app** in Applications and choose **Open**, then confirm. On recent macOS versions you may instead need to go to **System Settings → Privacy & Security** and click **Open Anyway**. You only need to do this once.
:::

  </TabItem>
  <TabItem value="linux" label="Linux">

1. Download the `.deb` package from the [download page](/download).
2. Open the downloaded file in your file manager. If a security warning appears, choose **Run Anyway**.
3. Follow the installer.
4. Launch Lumark from your applications menu.

You can also install it from a terminal:

```bash
sudo apt install ./Lumark_<version>_amd64.deb
```

  </TabItem>
</Tabs>

## First launch

On first launch Lumark creates a folder called **general** and opens it. Create a note with the **+** button in the notes panel and start typing. Everything is saved automatically.

Next: [Folders and notes](../your-notes/folders-and-notes.md).

## Updating

Download the newer installer from the [download page](/download) and install it over the existing version. Your notes are stored separately from the app (see [Where your notes live](../your-notes/where-notes-live.mdx)) and are not touched by an update.
