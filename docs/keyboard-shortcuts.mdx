# Keyboard shortcuts

:::info[Coming soon]
Formatting shortcuts such as <kbd>Ctrl</kbd> + <kbd>B</kbd> for bold, <kbd>Ctrl</kbd> + <kbd>I</kbd> for italic and <kbd>Ctrl</kbd> + <kbd>U</kbd> for underline, plus <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> for indenting, are on the [roadmap](https://github.com/AlbertArakelyan/Lumark#roadmap). This page will list them once they ship.
:::

## Available today

The editing pane already supports the standard editing keys. On macOS, use <kbd>Cmd</kbd> wherever <kbd>Ctrl</kbd> is shown.

| Action | Shortcut |
| --- | --- |
| Undo | <kbd>Ctrl</kbd> + <kbd>Z</kbd> |
| Redo | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> or <kbd>Ctrl</kbd> + <kbd>Y</kbd> |
| Find and replace in the note | <kbd>Ctrl</kbd> + <kbd>F</kbd> |
| Select the next occurrence of the selection | <kbd>Ctrl</kbd> + <kbd>D</kbd> |
| Select all | <kbd>Ctrl</kbd> + <kbd>A</kbd> |
| Move line up / down | <kbd>Alt</kbd> + <kbd>↑</kbd> / <kbd>↓</kbd> |
| Copy line up / down | <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>↑</kbd> / <kbd>↓</kbd> |
| Delete line | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> |

When naming a folder or note:

| Action | Shortcut |
| --- | --- |
| Confirm the name | <kbd>Enter</kbd> |
| Cancel | <kbd>Esc</kbd> |
